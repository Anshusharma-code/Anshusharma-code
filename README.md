## 👋 Hey, I'm Anshu

I'm a **Computer Science student and aspiring AI/ML Engineer** who enjoys turning ideas into practical AI applications.

I work mostly with **Python, Machine Learning, GenAI and backend development**, and I'm currently exploring how modern AI systems are built beyond notebooks — from LLM-powered applications to RAG pipelines and AI agents.

> **Learn → Build → Break → Fix → Ship.**

## 🚀 What I've Built

### 🤖 HireLens AI

An AI-powered resume analyzer that helps job seekers understand how well their resume matches a job description.

**Built with:** Python · FastAPI · Gemini · PostgreSQL · React

→ Resume + Job Description → AI analysis → actionable feedback

---

### 📈 BizBoost AI

A GenAI-powered marketing assistant built to help local businesses create platform-specific content and marketing ideas.

**Built with:** React · FastAPI · Gemini · PostgreSQL

**Status:** Working V1

→ Generate → refine → create content that businesses can actually use

---

### 🧠 CODE-A-NOVA

A collection of machine learning projects built during my ML internship, covering different datasets, models and ML workflows.

**Focus:** Machine Learning · Data Preprocessing · Model Training · Evaluation
